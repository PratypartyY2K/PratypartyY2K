**C++ · gRPC · Multi-threading · Distributed Systems**

A multi-threaded MapReduce framework built in C++ using gRPC for distributed execution.

* Built distributed map and reduce execution across worker processes
* Implemented reducer-side batching and synchronization improvements

### Distributed Key-Value Store

**C++ · gRPC · Quorum Protocols · Distributed Consistency**

A distributed key-value store implementing quorum-based read/write behavior with a focus on consistency and fault tolerance.

* Implemented client-server communication using **gRPC and Protobuf**
* Built read/write operations using **majority quorum semantics**
* Explored consistency behavior through ABD-style non-blocking protocols and blocking variants
* Tested system behavior across multi-node configurations
* Focused on correctness, concurrency, and distributed coordination under partial failures

## 🧩 How I Think About Systems

I like systems that are:

### Understandable

Simple designs beat clever chaos. Every component should have a clear reason to exist.

### Observable

A system should tell you what it is doing, why it is doing it, and where it is falling apart.

### Sustainable

Scalable systems stay clean only when design choices are deliberate. Otherwise they become distributed spaghetti, which is impressive only in the sense that sinkholes are impressive.
